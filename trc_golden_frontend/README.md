# ТРЦ Золотой — фронтенд демо

Состав:
- `index.html`
- `styles.css`
- `js/app.js`
- `js/data.js`
- `js/ui.js`
- `js/filters.js`
- `js/theme.js`
- `js/budget.js`
- `js/vor.js`
- `js/localsmeta.js`
- `js/ks2.js`

Запуск:
1. открыть `index.html` в браузере
2. либо поднять статический сервер:
   - `python -m http.server 8000`
   - затем открыть `http://localhost:8000`

Что реализовано:
- SPA-подобная навигация без перезагрузки
- тёмная/светлая тема
- блоки: один / несколько / все
- экраны: Главная панель / ВОР / Бюджет / Локальные сметы
- глобальный поиск
- экспорт CSV / JSON текущего среза
- inline-редактирование ВОР
- модуль КС-2 с загрузкой и сопоставлением
- сохранение пользовательского состояния в localStorage
